# muxdev v0.2 Four-Minute Demo

Run `muxdev demo --scenario trusted-delivery-v1 --mode replay` when no Provider
credentials or network are available. The fixture hash printed by the CLI must
match the Dashboard scenario.

1. **0:00-0:40 — Route:** show verified capability filters, candidate
   exclusions and the selected managed main Agent.
2. **0:40-1:25 — Review:** show the fingerprint-distinct Replay reviewer and
   frozen read-only snapshot.
3. **1:25-2:10 — Recovery:** show checkpoint reclaim and stale fencing-token
   rejection.
4. **2:10-2:50 — Reconciliation:** show why opaque effects are not replayed
   without an explicit operator decision.
5. **2:50-4:00 — Trust:** show Evidence, signed DeliveryAttestation,
   self-asserted identity, fingerprint pinning and tamper failure.

Replay is simulation. For the real runtime path use `--mode live`; it still
uses Mock/Replay and must not be presented as paid Provider benchmark evidence.
